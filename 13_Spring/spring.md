# Spring :: Spring Framework

- 스프링 프레임워크는 자바 엔터프라이즈 개발을 편리하게 해주는 오픈 소스 경량급 애플리케이션 프레임워크이다.
- 스프링은 EJB(Enterprise JavaBeans)의 복잡함을 해결하고, POJO(Plain Old Java Object) 기반의 프레임워크로서 엔터프라이즈 개발을 편리하게 해준다.
- 스프링은 DI(Dependency Injection)와 AOP(Aspect-Oriented Programming)을 지원한다.
- 스프링은 컨테이너로서 객체의 생명주기와 설정을 관리한다.
- 스프링은 스프링 MVC를 통해 웹 개발을 지원한다.
